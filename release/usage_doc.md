# FolderSync 使用说明

> 下载/位置：单文件 `FolderSync.App.exe`（约 5MB，免安装，放任意目录即可运行）
>
> **运行前提**：机器上需已安装 .NET 8 Desktop Runtime。缺失时双击 exe 会弹官方引导框「未能找到 .NET 运行时，是否立即下载？」，点「是」跳转官方下载页，装完即可运行。

## 快速上手

1. 双击 `FolderSync.App.exe`——会自动请求管理员权限（USN 实时监控需要；你的 UAC 是免提示模式，无感提权）
2. 点「新建任务」：
   - 任务名称：随意
   - 左/右文件夹：选择两侧目录（左侧=源，右侧=目标）
   - 方向：左→右 或 右→左（单向镜像）
   - 触发：手动 / 实时监听（文件变化自动同步，默认 10s 去抖）/ 定时间隔
   - **镜像删除**：默认关。关闭时源里删掉的文件在目标保留；开启后目标同步删除。**首次建任务建议先关，跑几轮确认差异列表没问题再开**
   - 排除规则：分号分隔，支持通配符（*.tmp）或路径段名（.git）
3. 点「分析」：先看差异列表（新建/覆盖/删除逐项列出），确认无误再「同步」
4. 「开机自启（启动后自动同步）」：勾上后创建 Windows 计划任务（登录时以管理员自动拉起），开机自动运行并补跑一次同步（离线期间的变更不会漏）

## 安全机制

- 首次同步前必须先分析，差异列表一目了然
- 删除默认进回收站（网络路径除外），可从回收站还原
- 目标目录不存在会自动创建
- 空路径任务不会启动（会提示编辑）
- **覆盖/替换类文件先写临时文件再原子改名**（v1.2）：中途断电/杀进程不会留下半个文件，残留 tmp 下轮自动清扫
- **版本保留**（v1.3 升级为块级去重）：任务编辑里「版本保留代数」设 N>0 时，被覆盖/删除的文件先归档进版本库——内容切块、按块去重、逐块压缩（大文件小改每版只占 1-2MB，同内容零成本），超代自动清理；任务卡「浏览版本库」按文件列历史版本，支持还原到原位置/另存/删除，「清空版本库」一键清空；FAT32/exFAT 盘同样可用。**版本库集中放在程序目录 `versions\` 下**（不占被同步的文件夹；每侧一库按路径哈希分目录，目录里 `side.txt` 记录归属），因此版本块占程序所在盘的空间。同步文件夹里若有历史版本残留的 `_FolderSync_Versions` 目录（旧版程序产生），不会被本程序读取也不会被同步，确认无用后可手动删除
- **失败明细与重试**（v1.2）：同步部分失败时状态标 partial，任务卡「上次失败明细」弹窗逐条看；可一键重试只补失败项；通知做了节流不刷屏
- **U 盘热插拔**（v1.2）：目标盘拔掉后任务转「等待介质」待命，插回自动恢复监控并补跑，不用重启程序

## 常见问题

- **右下角托盘**：关窗口、点最小化都不退出，收进托盘同步继续跑（实时/定时任务）；双击托盘图标恢复窗口，彻底退出走托盘右键菜单
- **开机自启**：勾上后 Windows 登录自动拉起本程序；旁边的「自启时最小化」控制登录后是直接驻留托盘还是显示主窗口。注意：任务何时同步由各任务的「启用 + 触发方式」决定（启用+实时的任务在软件打开时会自动补跑一轮对齐离线期间的变更），与开机自启开关无关
- **状态栏显示"监听失败"**：多半是没提权或目录不可访问；重启程序以管理员身份运行
- **定时任务没跑**：任务启用了吗？触发方式选对了吗？
- **实时日志**：底部日志区文字可拖选，右键支持「复制选中行 / 复制全部日志 / 清空日志」
- **crash.log**：程序目录下，出错时自动写入，报问题时带上

## 已知限制

- 实时监控（USN）仅支持本地 NTFS 盘；网络盘/非 NTFS 自动降级为 FSW 监控（可靠性略低）
- 双向同步（快照基线 + 冲突三策略）v1.0 已实现
- 文件冲突（两侧同 mtime 不同内容）标记为 ⚠ 冲突，默认按方向覆盖，请人工确认
